# Ícones — GestorFrete ERP

`lucide-react` — biblioteca padrão do shadcn/ui, já usada pelos componentes base (`X`, `Check`,
`ChevronRight`, `Search`, `Menu`, etc.) e pelo `nav-config.ts` (um ícone por item de menu). Traço
consistente (stroke-based, `stroke-width: 2` por padrão), tamanho controlado via classes Tailwind
(`h-4 w-4` no corpo de componentes, `h-5 w-5` em contextos de destaque como o cabeçalho do login).

Sem SVGs customizados neste lote — o catálogo do Lucide cobriu todo ícone necessário até aqui
(módulos de navegação, ações de UI). Revisar apenas se um ícone de domínio muito específico
(ex. selo fiscal, ícone de CT-e) for pedido em um lote futuro.
