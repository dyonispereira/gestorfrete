# Modules (specs por tela/funcionalidade)

Esta pasta está **preparada, mas vazia** — nenhum arquivo de especificação foi criado ainda. Ela
existe para receber, em etapas futuras, um arquivo de especificação por tela/funcionalidade do
produto, numerado sequencialmente para refletir a ordem de construção:

```
NNN-nome-da-tela-ou-funcionalidade.md
```

Exemplo do que é esperado no futuro (nenhum destes arquivos existe ainda):

```
001-dashboard.md
002-cadastros.md
003-clientes.md
004-motoristas.md
005-veiculos.md
...
040-app-motorista.md
050-landing.md
```

Cada arquivo, quando criado, deve descrever a tela/funcionalidade correspondente com o mesmo nível
de rigor documental do restante de `docs/` — ver [`docs/product/SCREENS.md`](../product/SCREENS.md)
para o inventário de telas planejadas e [`docs/product/USER_STORIES.md`](../product/USER_STORIES.md)
para as histórias de usuário que originam cada uma.
