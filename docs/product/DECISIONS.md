# DECISIONS.md — Registro de Decisões

**Regra do projeto, em vigor a partir de agora:** toda decisão arquitetural ou de produto que
afete mais de uma tela/módulo entra aqui. Este documento é consultado **antes** de qualquer
implementação — se uma decisão relevante já está registrada aqui, ela não é rediscutida a cada
sprint, apenas aplicada. Decisões aqui têm o mesmo peso de [`VISION.md`](./VISION.md) e de
[`PRODUCT_PRINCIPLES.md`](./PRODUCT_PRINCIPLES.md): prevalecem sobre uma escolha pontual feita
dentro de uma tarefa isolada, até serem explicitamente revistas.

Cada linha é intencionalmente uma frase — a justificativa longa, quando existir, mora no documento
de origem linkado em "Detalhado em"; este documento é o índice rápido, não a explicação.

## Como adicionar uma nova decisão

1. Confira que a decisão ainda não está registrada (evita duplicar/contradizer uma linha existente).
2. Adicione uma linha nova com o próximo ID sequencial, a decisão em uma frase, a área e, se a
   decisão for elaborada em outro documento, o link para ele.
3. Se a decisão for grande o suficiente para merecer contexto/alternativas consideradas (o nível de
   detalhe de um ADR), registre o ADR completo em [`../adr/`](../adr/) e linke-o aqui — este
   documento não substitui os ADRs, é o índice que aponta para eles e para as demais decisões
   menores que não justificam um ADR próprio.
