# @gestorfrete/ui

Biblioteca de componentes de UI compartilhada entre aplicações do monorepo (hoje `apps/web`;
futuramente uma eventual segunda aplicação front-end, como um app mobile-web ou painel interno).

Contém os componentes gerados pelo `shadcn/ui` que forem promovidos de `apps/web/src/shared/components`
para reúso entre aplicações — nesta etapa de fundação, nenhum componente foi implementado ainda.
